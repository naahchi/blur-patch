महत्वपूर्ण सीमाएँ

  • यह संस्करण watermark को reconstruct नहीं करता; selected area को blur, pixelate या clone patch से ढकता है।
  • Canvas 2D से patch बनता है। WebCodecs encoding और Mediabunny demux/mux के लिए है। Mediabunny केवल container/codec handling करता है, image processing नहीं।
  • Browser में WebCodecs अकेले MP4 file नहीं बनाता; MP4 container में encoded frames रखने के लिए muxer जरूरी है।
  • वीडियो दोबारा encode होगा, इसलिए original codec और bitrate समान नहीं रहेंगे। Original timestamps/frame timing रखने का प्रयास होगा।
  • पहले 5–10 सेकंड का टेस्ट करें। Original resolution और लंबी अवधि मोबाइल पर भारी हो सकती है।
